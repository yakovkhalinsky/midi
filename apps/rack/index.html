Rack — up to 3 apps · shared clock

Stacks app cards in a column on one clock: one BPM, one RUN/STOP, one RESET. Each card is a live instance of an app in compact mode — its parameters, voice and MIDI routing stay inside the card; the transport here drives every slot. Clock edges can be divided per slot (÷N) so apps running at different clock rates (e.g. TB-3PO 16ths vs DrumMap 32nds) stay in sync.

OUTPUT
MIDI Web MIDI: idle

Shared-clock rack for the web sequencer ports. Slots run the real apps (same settings as their standalone pages — localStorage is shared per origin). Click inside a card once if its audio doesn't start (browser autoplay policies); the enable buttons inside each card always work.
